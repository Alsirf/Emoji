# Миграция эмодзи в ClickHouse

Инструкция для тестировщика по миграции данных эмодзи между базами ClickHouse.

## 📁 Структура репозитория

clickhouse-emoji-migration/
├── README.md # Краткая инструкция по шагам
├── scripts/
│ └── collect_emojis.py # Скрипт для сбора эмодзи
└── sql/
├── 01_create_table.sql # Создание таблицы
├── 02_migrate.sql # Миграция в новую БД
└── 03_compare_hashes.sql # Сравнение по хешам


## 📋 Порядок действий

### 1️⃣ Подготовка
- [ ] Создать таблицу в старой БД (`sql/01_create_table.sql`)
- [ ] Создать таблицу в новой БД (`sql/01_create_table.sql`)

### 2️⃣ Сбор данных
```bash
python scripts/collect_emojis.py
```

📁 Результат: data/emojis_with_codes.csv

### 3️⃣ Импорт в старую БД

Через DBeaver импортировать emojis_with_codes.csv:
- Разделитель: `,`
- Кодировка: `UTF-8`
- Заголовки: есть

### 4️⃣ Миграция в новую БД
Выполнить в старой БД: sql/02_migrate.sql
⚠️ Заменить хост, порт, логин, пароль, имя таблицы


### 5️⃣ Проверка целостности
Сравнить хеши: sql/03_compare_hashes.sql
⚠️ Заменить параметры подключения к новой БД


## ✅ Критерии успеха
Количество записей совпадает (~3800)
Нет NULL и дубликатов
В сравнении хешей: only_in_new = 0 и only_in_old = 0
